# 스터디룸 예약 서비스 화면설계서 (샘플)

sb-lowfi 스킬의 입력 형식을 보여 주는 가상의 예시입니다. 실제 서비스와 관계없습니다.

## 화면 목록

| Screen ID | 화면명 | 플랫폼 | 우선순위 |
|-----------|--------|--------|----------|
| SCR-001 | 로그인 | 모바일+PC 반응형 | P0 |
| SCR-002 | 스터디룸 목록 | 모바일 전용 | P0 |
| SCR-003 | 예약 관리 (관리자) | PC 전용 | P1 |

---

### SCR-001. 로그인

| 항목 | 내용 |
|------|------|
| URL | /login |
| 플랫폼 | 모바일+PC 반응형 |
| 접근 권한 | 전체 공개 (로그인 상태면 SCR-002로 이동) |
| 관련 기능 | F-001 이메일 로그인, F-002 소셜 로그인 |
| 관련 API | API-001 POST /auth/login, API-002 GET /auth/oauth/{provider} |

**레이아웃**

```
+------------------------------------------+
| [로고 StudyRoom]                          |
|------------------------------------------|
|            스터디룸 예약에 로그인            |
|   [이메일 입력칸                       ]   |
|   [비밀번호 입력칸                     ]   |
|   [ ] 로그인 유지        비밀번호 찾기 >    |
|   [          로그인           ]            |
|   ------------- 또는 -------------         |
|   [ 카카오로 시작 ] [ 구글로 시작 ]          |
|   아직 회원이 아니신가요? 회원가입 >         |
+------------------------------------------+
```

**UI 컴포넌트**

| No. | 컴포넌트 | 설명 / 인터랙션 |
|-----|----------|-----------------|
| 1 | 글로벌 헤더 | 로고를 누르면 홈 |
| 2 | 이메일 입력 | 이메일 형식 검사, 포커스를 잃을 때 오류 표시 |
| 3 | 비밀번호 입력 | 8자 이상, 눈 아이콘으로 표시/숨김 |
| 4 | 로그인 유지 | 체크 시 30일 유지 |
| 5 | 비밀번호 찾기 | 비밀번호 재설정 화면으로 이동 |
| 6 | 로그인 버튼 | 두 입력이 모두 유효할 때만 활성 |
| 7 | 소셜 로그인 | 카카오, 구글. 처음이면 약관 동의 후 가입 |
| 8 | 회원가입 링크 | 회원가입 화면으로 이동 |
| 9 | 오류 안내 | 로그인 실패 시 입력칸 위에 표시 |

**상태별 화면**

| 상태 | 조건 | 표시 내용 |
|------|------|-----------|
| 기본 | 처음 진입 | 빈 입력칸, 로그인 버튼 비활성 |
| 입력 오류 | 이메일 형식이 틀림 | 입력칸 아래 [오류] 문구 |
| 로그인 실패 | 이메일 또는 비밀번호 불일치 | 상단 [오류] 안내, 비밀번호 칸 비움 |
| 잠김 | 5회 연속 실패 | 10분 뒤 다시 시도 안내, 로그인 버튼 비활성 |

**처리 규칙**

- 실패 횟수는 계정 단위로 세고, 성공하면 0으로 초기화한다
- 오류 문구는 이메일과 비밀번호 중 무엇이 틀렸는지 알려 주지 않는다
- 로그인 성공 시 직전에 보던 화면으로, 없으면 SCR-002로 이동한다

### SCR-002. 스터디룸 목록

| 항목 | 내용 |
|------|------|
| URL | /rooms |
| 플랫폼 | 모바일 전용 |
| 접근 권한 | 로그인 사용자 |
| 관련 기능 | F-010 스터디룸 조회, F-011 날짜·인원 필터, F-012 즐겨찾기 |
| 관련 API | API-010 GET /rooms, API-012 POST /rooms/{id}/favorite |

**레이아웃**

```
+-----------------------+
| StudyRoom        [=]  |
| [날짜 10/29 v][4명 v]  |
| (전체)(4인)(6인)(8인)   |
| +-------------------+ |
| | A룸  4인  [*]     | |
| | 10:00~ 예약 가능   | |
| +-------------------+ |
| | B룸  6인  [ ]     | |
| +-------------------+ |
| [ 하단 탭 바        ] |
+-----------------------+
```

**UI 컴포넌트**

| No. | 컴포넌트 | 설명 / 인터랙션 |
|-----|----------|-----------------|
| 1 | 날짜 선택 | 오늘부터 14일 이내만 선택 |
| 2 | 인원 선택 | 1~10명 |
| 3 | 크기 필터 | 전체/4인/6인/8인, 하나만 선택 |
| 4 | 스터디룸 카드 | 이름, 수용 인원, 가장 빠른 예약 가능 시간. 누르면 상세 |
| 5 | 즐겨찾기 | 토글, 즐겨찾기한 방이 목록 위로 |
| 6 | 하단 탭 바 | 목록 / 내 예약 / 마이 |
| 7 | 빈 상태 안내 | 조건에 맞는 방이 없을 때 필터 초기화 버튼 |

**상태별 화면**

| 상태 | 조건 | 표시 내용 |
|------|------|-----------|
| 로딩 | 목록 조회 중 | 카드 자리에 회색 스켈레톤 3개 |
| 빈 상태 | 조건에 맞는 방 없음 | [안내] 문구 + 필터 초기화 버튼 |
| 오류 | 조회 실패 | [오류] 문구 + 다시 시도 버튼 |

**처리 규칙**

- 필터를 바꾸면 즉시 다시 조회하고, 선택값은 URL 쿼리에 남긴다
- 예약 가능한 시간이 없는 방은 카드를 흐리게 표시하고 맨 아래로 보낸다

### SCR-003. 예약 관리 (관리자)

| 항목 | 내용 |
|------|------|
| URL | /admin/reservations |
| 플랫폼 | PC 전용 |
| 접근 권한 | admin |
| 관련 기능 | F-030 예약 현황 조회, F-031 예약 취소, F-032 노쇼 처리 |
| 관련 API | API-030 GET /admin/reservations, API-031 PATCH /admin/reservations/{id} |

**레이아웃**

```
+--------------------------------------------------------------+
| StudyRoom 관리자                         관리자 홍길동 로그아웃 |
|------------+-------------------------------------------------|
| 대시보드    | 예약 관리                                         |
| [예약 관리] | [기간 v] [스터디룸 v] [상태 v] [검색        ] [조회] |
| 스터디룸    | +-----------------------------------------------+ |
| 회원        | | 예약번호 | 스터디룸 | 예약자 | 시간 | 상태 | 관리 | |
|            | +-----------------------------------------------+ |
|            | [ < 1 2 3 > ]                    [엑셀 다운로드] |
+--------------------------------------------------------------+
```

**UI 컴포넌트**

| No. | 컴포넌트 | 설명 / 인터랙션 |
|-----|----------|-----------------|
| 1 | 사이드 메뉴 | 현재 메뉴 강조 |
| 2 | 검색 필터 | 기간(기본 오늘), 스터디룸, 상태, 예약자 검색 |
| 3 | 조회 버튼 | 필터 조건으로 다시 조회 |
| 4 | 예약 표 | 예약번호, 스터디룸, 예약자, 시간, 상태. 열 머리글로 정렬 |
| 5 | 상태 배지 | 예약됨/이용중/완료/취소/노쇼. 문구와 모양으로 구분 |
| 6 | 관리 버튼 | 취소, 노쇼 처리. 처리 전 확인 창 |
| 7 | 페이지 이동 | 20건 단위 |
| 8 | 엑셀 다운로드 | 현재 조건의 전체 결과 |

**상태별 화면**

| 상태 | 조건 | 표시 내용 |
|------|------|-----------|
| 결과 없음 | 조건에 맞는 예약 없음 | 표 자리에 [안내] 문구 |
| 처리 확인 | 취소/노쇼 버튼 클릭 | 확인 창(사유 입력 필수) |

**처리 규칙**

- 이용 시작 시각이 지난 예약은 취소할 수 없고 노쇼 처리만 할 수 있다
- 모든 처리는 처리자와 사유를 이력에 남긴다
